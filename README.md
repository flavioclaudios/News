# 📡 Radar de Inteligência Diária

Dashboard pessoal em modo dark desenvolvido com Streamlit, agregando telemetria meteorológica de São Paulo (Open-Meteo) e feeds RSS em tempo real de tecnologia, automobilismo, esportes e notícias locais/globais.

## 🚀 Como rodar localmente

```bash
pip install -r requirements.txt
streamlit run radarnoticias.py
